# 비시장 모델 — 배당률 없이 피처만으로

프로젝트 흐름 **3단계**에 해당하는 코드입니다.

2단계에서 시장(배당률)이 모델보다 정확하다는 게 확인됐습니다. 그래서 던진 질문이 이것입니다 — **배당률을 전혀 쓰지 않고, 말·기수·조교 데이터만으로 시장에 얼마나 가까이 갈 수 있는가.**

시장의 ROC-AUC 약 0.82가 목표선이었고, 피처를 늘렸다 줄였다 하며 그 선에 접근하려 했습니다. 결론부터 말하면 **넘지 못했습니다.** 그 과정을 남긴 코드입니다.

> 이 폴더의 스크립트는 주석과 도움말이 영문으로 작성돼 있습니다.

---

## 실행 순서

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `train_market_free_model.py` | 기준 모델 학습. v1~v8 전처리 버전별로 돌립니다. 나머지 스크립트가 이 파일을 불러 씁니다 |
| 2 | `02_select_rf_features.py` | 랜덤포레스트 — 피처를 30개에서 20개까지 하나씩 빼며 성능 변화 관찰 |
| 3 | `03_select_xgb_features.py` | XGBoost — 30~50개 구간에서 최적 피처 수 탐색 |
| 4 | `04_search_xgb_50_to_100.py` | XGBoost — 50개에서 100개까지 5개씩 늘려가며 확인 |

```bash
python train_market_free_model.py --version v1
python 02_select_rf_features.py --version v1
```

---

## 실험 설계에서 지킨 것

**당일 시장 계열을 전부 제외해야 합니다.** 현재 `v1_base`에는 명시적 배당률 열은 없지만 발매금액 5개와 시장 파생 `gap_h`, `gap_d`가 있으므로 모두 제외해야 합니다. 엄격 제외 후 원천 후보 수는 100개이며, 102개 주장과의 차이는 [`../피처수_감사.md`](../피처수_감사.md)에 기록했습니다.

**피처 수를 고를 때 valid만 봤습니다.** test는 마지막 한 번만 열었습니다. 피처 후보를 비교하면서 test 점수를 참고하면, 그 test 점수는 더 이상 미래 성능의 추정치가 아니게 됩니다.

---

## 결과

피처를 20개까지 줄여도, 100개까지 늘려도 검증 성능의 최고점은 넓은 피처셋에서 나타났습니다. **피처를 단순히 줄이는 것이 해답은 아니었다**는 것이 이 실험의 결론입니다.

같은 데이터로 만든 모델은 시장이 이미 반영한 정보를 다시 정리할 뿐이고, 시장에는 그 밖에 마방 분위기·당일 컨디션·내부 정보처럼 데이터에 없는 신호가 들어가 있습니다.

이 판단의 근거가 된 문헌 조사는 [`reports/3_시장대조/06_문헌조사_시장대조.docx`](../../발표자료/파트1_시장이라는_벽/근거자료/4_문헌조사.pdf)에 정리돼 있고, 여기서 얻은 인사이트가 **5단계 이변 분석으로 방향을 트는 근거**가 됐습니다.
