# revised_v5 모델 평가 보고서

## 데이터와 평가 규칙

- 시간 순서 분할: train 19,617행/1,891경주, valid 6,582행/641경주, test 6,639행/635경주.
- 문자열 처리: 단순 범주는 One-Hot, 장구류는 Multi-Hot(32개), 기수·조교사·마주·등급은 train 기준의 시간순 Target Encoding이다.
- EDGE 평가는 경주별 최대 EDGE 말 1두만 남긴 뒤, 유효 배당률을 가진 635경주의 상위 10%(64회)만 사용했다. 따라서 ROI는 고변동성 참고치이며 단독 채택 기준이 아니다.
- 시장 기준 test ROC-AUC / PR-AUC: **0.8122 / 0.3303**.

## 테스트 결과

| 모델 | Test ROC-AUC | Test PR-AUC | 상위 10% EDGE ROI | 평균 실현 EDGE | EDGE-실현 상관 |
|---|---:|---:|---:|---:|---:|
| LightGBM rank+binary | **0.7552** | - | +45.0% | **+0.0585** | 0.0357 |
| CatBoost ordered | 0.7508 | 0.2637 | +13.3% | +0.0030 | 0.0257 |
| Random Forest | 0.7507 | - | **+55.0%** | +0.0229 | **0.0369** |
| XGBoost | 0.7419 | 0.2531 | +55.0% | +0.0203 | 0.0210 |

## 해석과 권고

1. **확률 예측 우선 후보는 LightGBM**이다. 네 모델 중 테스트 ROC-AUC가 가장 높고, 상위 10%의 평균 실현 EDGE도 가장 높다.
2. Random Forest와 XGBoost의 +55.0% ROI는 64회 선택 표본 결과다. 실현 EDGE와 상관이 낮으므로 수익성 확정 근거가 아니라, 별도 기간 walk-forward에서 재현해야 할 가설이다.
3. 모든 모델의 ROC-AUC는 시장 0.8122에 못 미친다. 운영에서는 단독 승률 예측 대신 시장확률을 기준으로 한 잔차/혼합 모델만 후보로 유지한다.
4. PyTorch 런타임 DLL 잠금과 원본 순위 라벨 파일 부재로 딥러닝·순위분포 모델은 이번 실행에서 학습하지 못했다. 이를 해소한 뒤 동일한 v5 고정 분할에서 추가 비교해야 한다.

## 주요 신호

Random Forest 상위 중요 피처는 `age__pr`, `hr_last_ord`, `hr_plcrate`, `jk_winrate__z`, `jk_plcrate`, `style_vs_race`, `te_jkName`, `train_runs_14__z`였다. 최근 성적·누적 성적·기수 폼·주행 스타일과 시간순 기수 인코딩이 반복적으로 의미 있는 신호를 보였다.
