# 1_변별력 — 1착을 가장 잘 골라내는가

각도 ①입니다. 가장 직관적인 질문이고 가장 먼저 던진 질문입니다.

## 세 번의 시도

| | 폴더 | 최고 성능 | 무엇을 배웠나 |
|---|---|---|---|
| 1차 | `1차_승률모델/` | RandomForest **0.7495** | 정확도만 보면 안 된다 |
| 2차 | `2차_비시장모델/` | XGBoost 95피처 **0.7529** (valid) | **피처를 늘릴수록 좋아졌다** — 가설이 뒤집힘 |
| 3차 | `3차_모델6종/` | LightGBM **0.7623** (무배당) | 검증 1위가 실전 1위가 아니다 |

시장은 **0.8126**입니다. 세 번 다 넘지 못했습니다.

## 3차_모델6종 — 이종원님 v5

`revised_v5_legacy_package`에서 가져왔습니다. 여섯 모델을 비교했고, 그중
**수업에서 다룬 세 가지**(LightGBM · CatBoost · RandomForest)를 발표에 씁니다.

```bash
cd 1_변별력/3차_모델6종
python src/train_preprocessed_models.py --model lightgbm --dataset full
```

### 두 가지 주의

**① `src/common/` 3개는 stub입니다.** 원본 패키지에 포함되지 않아 직접 만들었습니다.
셋 다 학습에 관여하지 않는 부속 산출물이고, **stub으로 돌린 결과가 원본 `metrics.json`과
소수점 12자리까지 일치**함을 확인했습니다.

**② 128개 피처에 시장 정보 5개가 섞여 있습니다.**
`winAmt` · `plcAmt` · `totalAmt` · `log_winAmt` · `liq_per_horse` 입니다.
이종원님이 사후 감사로 직접 밝히신 내용입니다.

전부 **경주 단위 총액**이라 같은 경주의 모든 말이 같은 값을 갖습니다.
말 하나하나의 인기도를 베낀 것은 아니지만, 파트 1 보고서 2.3절의
"배당·베팅 정보 제외" 원칙에는 어긋납니다.

**제거하고 다시 학습해봤더니 오히려 좋아졌습니다.**

| 모델 | 128피처 | **123피처 (무배당)** | 차이 |
|---|---:|---:|---:|
| LightGBM | 0.7569 | **0.7623** | **+0.0054** |
| RandomForest | 0.7490 | 0.7498 | +0.0008 |
| CatBoost | 0.7512 | 0.7512 | ±0.0000 |

경주 단위 값이라 경주 안에서 말을 구분하는 정보가 없고, 트리 모델에는
**분기 후보만 늘리는 잡음**이었던 것으로 보입니다. 결론에 영향은 없습니다.
