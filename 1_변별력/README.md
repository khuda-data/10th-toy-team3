# 파트 1 — 변별력

최종 발표에서는 배당률을 입력하지 않은 독립 모델이 시장보다 우승 후보를 잘 구분하는지 확인합니다.

| 단계 | 폴더 | 발표에서의 역할 |
|---|---|---|
| 1차 | [`1차_승률모델/`](1차_승률모델/) | 초기 Random Forest와 시장 기준선 비교 |
| 2차 | [`2차_비시장모델/`](2차_비시장모델/) | 피처 수를 줄이고 늘리며 ROC-AUC 변화 확인 |
| 3차 | [`3차_4모델비교_재실행필요/`](3차_4모델비교_재실행필요/) | LightGBM·CatBoost·RF·XGBoost의 엄격한 비시장 재실행 계약 |

## 최종 해석

- 기존 비교에서는 네 모델이 시장 ROC-AUC보다 낮은 방향이 관측됐습니다. 다만 기존 v5에는 당일 발매금액 변수가 섞여 있어, 이 결과를 엄격한 비시장 4모델 최종표로 인용할 수는 없습니다.
- 피처를 줄이면 시장에 가까워질 것이라는 가설은 지지되지 않았습니다.
- 모델 성능은 많은 피처를 사용할수록 높아졌지만 시장과의 격차는 남았습니다.
- 시장의 우위는 소수 핵심 변수만 잘 고른 결과로 설명되지 않습니다.

Deep Listwise와 Plackett–Luce는 최종 발표 비교에서 제외했으며 관련 전용 결과도 이 브랜치에서 정리했습니다.

피처 수 실험의 방향은 2차 자료가 지지하지만, 네 모델의 정확한 Test 표는 엄격한 비시장 피처로 다시 실행해야 합니다. 기존 v5 4모델 결과에는 당일 발매금액이 포함돼 있어 최종 발표 근거에서 제외했습니다. `102개` 피처 주장과 실제 열 계약의 차이는 [`피처수_감사.md`](피처수_감사.md)를 확인합니다.
