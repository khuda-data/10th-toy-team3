# 변별력 피처 수 감사

확정 스토리라인은 “당일 시장 정보를 제외한 102개 전처리 피처”를 명시합니다. 저장소의 `v1_base`에는 원천 열이 111개 있습니다.

| 구분 | 개수 | 열 |
|---|---:|---|
| 전체 원천 열 | 111 | `v1_base` 헤더 |
| 타깃·기술 열 | 4 | `win`, `race_id`, `entry_id`, `fold` |
| 당일 시장 변수 | 7 | `winAmt`, `plcAmt`, `totalAmt`, `log_winAmt`, `liq_per_horse`, `gap_h`, `gap_d` |
| 엄격 제외 후 원천 후보 | **100** | 111 - 4 - 7 |

102개는 다섯 발매금액 열만 빼고 `gap_h`, `gap_d`를 남겼을 때의 수와 일치합니다. 그러나 기존 비시장 코드와 보고서는 두 `gap` 열도 현재 시장 파생변수로 분류합니다. 따라서 발표의 “102개”와 “당일 시장 정보 완전 제외”는 현재 저장소 기준으로 동시에 성립하지 않습니다.

발표 전 선택지는 두 가지입니다.

1. 시장 독립성을 유지한다면 피처 수를 100개 원천 후보로 정정하고, 전처리 후 실제 모델 입력 차원은 별도로 표시합니다.
2. 102개를 유지한다면 `gap_h`, `gap_d`의 생성 시점과 정의를 공개하고 왜 시장 정보가 아닌지 입증해야 합니다.

현재 근거에 맞는 권고는 1번입니다. 이 문서는 사용자가 제공한 확정 스토리라인 자체를 수정하지 않고, 발표 전에 해결해야 할 숫자·정의 충돌을 기록합니다.
