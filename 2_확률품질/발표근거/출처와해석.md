# 독립 확률 모델 Test 근거

수치는 `main`의 다음 원본 산출물에서 `models.*.metrics.standalone_model`만 옮겼습니다.

`src/3_시장대조/시장확률보정/reports/experiments/stage_15_final_test.json`

원본 보고서는 각 독립 모델에 시장 확률 95%와 모델 확률 5%를 혼합한 후보 및 temperature scaling 결과도 함께 기록합니다. 최종 발표에서는 그 후속 수치를 제외하고 아래 세 행만 비교합니다.

- 시장: 비교 기준선
- M1 Logistic: sum normalization을 적용한 독립 모델
- M2 XGBoost: sum normalization을 적용한 독립 모델

Log Loss와 Brier는 낮을수록 좋습니다. 두 독립 모델의 두 손실이 모두 시장보다 높으므로, “누가 유력한가”뿐 아니라 “얼마나 유력한가”에서도 시장이 우위였다는 결론을 지지합니다.
