# 확률 품질 — 최종 발표 사용 범위

이 패키지에는 독립 모델 이후의 시장 결합·온도 보정·게이트·미래 홀드아웃 연구 코드도 남아 있습니다. 최종 발표의 파트 1 질문은 **배당률을 입력하지 않은 독립 모델이 시장보다 좋은가**이므로 다음 범위만 사용합니다.

## 사용하는 구성

- `train_m1_logistic.py`: Logistic Regression 독립 확률 모델
- `train_m2_xgboost.py`: XGBoost 독립 확률 모델
- `select_normalization.py`: 경주별 확률 합을 1로 만드는 정규화 비교
- `race_metrics.py`: Race Log Loss·Race Brier Score
- `market_baseline.py`: 모델 입력이 아니라 비교 기준선으로만 사용
- [`발표근거/독립모델_test_지표.csv`](발표근거/독립모델_test_지표.csv): Final Test 독립 모델 수치

## 사용하지 않는 최종 주장

- 시장 확률과 모델 확률의 혼합 성과
- 시장을 앵커로 사용한 온도 보정 성과
- 후속 랭커·게이트의 후보 성과
- 기대수익 기반 베팅 가능성

독립 Logistic과 독립 XGBoost는 시장보다 높은 손실을 기록했으며, 최종 결론은 확률의 크기와 불확실성 배분에서도 시장 우위입니다.

`expected/metrics.json`에 있던 M2 수치는 시장 혼합과 temperature scaling까지 적용한 최종 후보 수치였으므로 독립 모델 근거와 혼동을 막기 위해 최종 `master`에서 제외했습니다.
