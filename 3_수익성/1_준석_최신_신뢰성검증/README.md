# 준석 모델 — 검증 계보 참고자료

이 폴더는 다크호스 모델을 별도 전처리와 시간 구간에서 재현하고, 부트스트랩·극단값 민감도·시간 후행 성능을 확인하는 최종 검증 흐름을 보존합니다.

최종 정리에서는 발표에 직접 필요한 재현·군집 부트스트랩·시간 후행 점검 코드만 [`코드/`](코드/)에 남겼습니다. 부산 전이, C 모델, 이단계 분류, 배당 절단 실험 등 발표에서 사용하지 않는 가지는 `main`과 Git 이력에만 보존합니다.

## 최종 발표에서 사용하는 범위

- 인기 하위 50% 중 3착 이내 입상을 다크호스로 정의한 점
- Random Forest 기반으로 소수 후보를 선별한 접근
- 수익률이 표본 수와 고배당 적중에 민감하다는 문제의식
- 시간순 검증과 홀드아웃이 필요하다는 방법론적 역할

## 사용하지 않는 수치

과거 보고서의 `최근 8주 ROI +101.6%`는 최종 발표 근거로 사용하지 않습니다. 원래 실행본은 부분집합 행 번호를 초기화한 뒤 원본 전체 데이터의 같은 행 번호로 배당을 가져와 배당과 말의 정렬을 보장할 수 없었고, 해당 기간도 완전히 독립적인 미관측 기간으로 보기 어려웠습니다. `master`의 코드는 배당을 부분집합 행에서 직접 가져오도록 수정했지만 과거 수치를 재사용하지 않으며, 새 결과를 주장하려면 수정 코드로 다시 실행해야 합니다.

공식 기존 Test 수치는 [`../2_찬진_최종_이변모델/`](../2_찬진_최종_이변모델/)의 잠금 결과를 사용하고, 최신 미관측 기간 결과는 [`../../발표자료/최종_발표/최신_백테스트_요약.csv`](../../발표자료/최종_발표/최신_백테스트_요약.csv)를 사용합니다.
