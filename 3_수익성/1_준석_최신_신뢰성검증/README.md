# 박준석 — 이변 예측 모델 신뢰성 검증 전체 과정

`경주마_이변예측모델_최종보고서.docx`를 만들어낸 코드입니다. 어제 완성된 이변
예측 모델(다크호스·인기마붕괴)의 표면 ROI가 배당 260배 적중 1건에 좌우된다는
문제를 발견한 뒤, 부트스트랩·홀드아웃·전이·대안모델 비교로 신뢰성을 재검증하고
최종적으로 "실전에서 쓸 수 있는 배당률 제외 모델"을 확정하기까지의 전 과정입니다.

## 읽는 순서

1. **`보고서/경주마_이변예측모델_최종보고서.docx`** — 전체 결론을 담은 최종 보고서. 이것부터 읽으면 됩니다.
2. `코드/` — 위 보고서의 각 절을 만들어낸 재현 코드. 아래 표 순서대로 진행됩니다.

## 코드 폴더 지도

| 폴더 | 무엇을 검증했나 | 핵심 결과 |
|---|---|---|
| `model_selection_validation/` | 다크호스(`upset_B`)·인기마붕괴(`upset_A`) 모델 재현, 부트스트랩 CI, 극단값 민감도, 진짜 홀드아웃, 통합분류기 비교, 인기마붕괴 실제 원본 코드 대조, 배당률(q) ablation | 다크호스 홀드아웃 ROI +101.6%(CI가 0을 배제, 유의함) |
| `c_model_validation/` | 배당률(q) 포함 C모델(`12_final_strategy.py` 계보)에 동일한 부트스트랩·홀드아웃·부경전이 검증 적용 | test ROI+32.0%(원본과 일치)이나 홀드아웃에서는 유의성 상실 |
| `busan_validation/` | 서울에서 학습한 다크호스·인기마붕괴 모델을 부산경남(부경) 데이터에 그대로 적용 vs 재학습 비교 | 다크호스는 재학습 필요, 인기마붕괴는 그대로 적용이 더 나음(정반대 결론) |
| `darkhorse_final/` | **최종 채택 모델**(배당률 제외 다크호스)로 배당구간 필터·인사이트·붕괴모델 조합·베팅 배분 전략까지 재수행 | 배당구간 필터는 홀드아웃에서 기각됨(ROI+3048%가 표본 16건짜리 착시); "필터 없음+상위10%+균등배분"이 최종 전략 |

각 하위 폴더 안의 스크립트는 파일명 번호 순서대로 실행하면 됩니다(`config.py`가 필요한 스크립트는 `src/pipeline/config.py`를 그대로 import합니다 — 이 저장소의 `src/1_전처리/` 등에 있는 것과 동일한 파일입니다).

## 왜 배당률 제외 모델로 최종 결론을 냈는가

배당률(`winOdds`/`plcOdds`)은 한국마사회 공공데이터 API 필드명("단승식**확정**배당")으로 확인한 결과 **베팅 마감 후 확정된 값**입니다. 마감 전 실시간 배당을 주는 공식 API는 없어, 배당률을 피처로 쓰는 모델(C모델)은 실전에서 쓸 수 없다는 게 오늘 검증 과정에서 확인됐습니다. 그래서 `darkhorse_final/`에서 배당률을 전혀 쓰지 않는 다크호스 모델로 같은 검증·전략 확정 과정을 다시 밟았고, 이게 최종 채택안입니다. C모델과 배당률 ablation 결과는 베팅 도구가 아니라 "시장이 이미 반영한 정보량"을 재는 참고 분석으로 보고서에 남겼습니다.

## 참고

- 학습된 모델(`.pkl`)이나 중간 결과 CSV는 용량 문제로 이 폴더에 올리지 않았습니다. 코드를 실행하면 재생성됩니다.
- 모든 코드는 프로젝트 루트의 `final.csv`(또는 이 저장소의 `data/race_entries.csv.gz`)를 입력으로 사용합니다.
