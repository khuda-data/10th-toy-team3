## 1. 목표

다음 두 모델을 서로 분리해 완성한다.

1. **다크호스 예측**: 인기 하위 50% 말 중 입상할 말을 선별
2. **인기마 붕괴 예측**: 인기 상위 25% 말 중 착순 하위 50%로 부진할 말을 선별

최종 산출물은 단순한 AUC 표가 아니라 다음을 모두 포함한다.

- 재현 가능한 학습·예측 코드
- 누수 검사 결과
- valid에서 고정한 모델·점수 임계값
- 잠금된 test 선별력
- 모델 예측 점수 상위 퍼센트별 예상·실현 ROI
- 경주 단위 부트스트랩 신뢰구간
- 연승배당 기반 ROI와 고배당 민감도
- 실전에 고정해 쓸 수 있는 경주별 선택 규칙

### 3.2 결합 검증

각 fold에서 다음 조건을 만족하지 못하면 즉시 중단한다.

- `entry_id`가 양쪽 데이터에서 유일함
- `many_to_many` 결합이 아닌 `one_to_one`
- 결합 전·후 행 수가 같음
- `pop_pct`, `place`, `fin_pct`, `plcOdds`, `race_id` 결측률 보고
- fold별 날짜 범위가 겹치지 않음
- 같은 `race_id`가 두 fold에 걸치지 않음

### 3.3 예상 표본

## 4. 라벨 및 부분집합

### 4.1 다크호스

```python
subset = df["pop_pct"] >= 0.50
target = df["place"] == 1
```

학습 대상은 인기 하위 50% 말만이고, 타깃은 입상 여부다. `upset_B`와 100% 일치하는지 검사하되 모델 코드에서는 정의식을 명시적으로 사용한다.

### 4.2 인기마 붕괴

```python
subset = df["pop_pct"] <= 0.25
target = df["fin_pct"] >= 0.50
```

학습 대상은 인기 상위 25% 말만이고, 타깃은 착순 하위 50% 여부다. `upset_A`와 100% 일치를 검증한다.

### 4.3 추가 타깃

기본 실험의 라벨을 바꾸지 않고 다음은 민감도 분석으로만 계산한다.

- 인기 임계: 40%, 50%, 60%
- 극단 격차: `abs(pop_pct - fin_pct)` 상위 5%
- 다크호스 1착: `pop_pct >= 0.50` 중 `win == 1`

## 8. 평가 지표

### 8.1 선별력

- 기저율
- ROC-AUC
- PR-AUC
- Lift@5%, 10%, 20%, 30%
- 상위 k% 적중률
- Brier score와 calibration curve(보조)

Lift는 절대 적중률과 항상 함께 표기한다.

### 8.2 실전 선택 규칙

두 방식을 구분한다.

1. **진단용**: 해당 fold 전체 점수의 상위 k%. 기존 보고서와 비교하기 위해 산출
2. **실전용**: valid에서 고정한 점수 임계값을 test에 그대로 적용하고, 각 경주에서 점수가 가장 높은 말 최대 1마리만 선택

실전용 규칙을 최종 결론으로 사용한다. test 자체의 상위 10% 개수를 사후적으로 맞추지 않는다.

### 8.3 상위 퍼센트 구간

모델 예측 점수를 높은 순으로 정렬한 뒤 다음 두 표를 생성한다.

1. **누적 상위 구간**: 상위 1%, 2%, 5%, 10%, 20%, 30%, 50%, 100%
2. **독립 점수 구간**: 0~1%, 1~2%, 2~5%, 5~10%, 10~20%, 20~30%, 30~50%, 50~100%

누적 표는 “상위 몇 %까지 베팅할 것인가”를 보여주고, 독립 구간 표는 범위를 늘릴 때 새로 추가되는 말들의 한계 가치를 보여준다.

퍼센트 기준은 test 결과를 보고 새로 정하지 않는다. 진단용으로는 미리 고정한 전체 구간을 모두 보고하고, 실전용 컷오프는 valid에서 한 번만 선택해 test에 고정 적용한다.

## 9. 수익률 계산

### 9.1 기본식

각 선택 말에 1단위를 균등 베팅한다.

```text
return_i = place_i * plcOdds_i - 1
ROI = sum(return_i) / number_of_bets
```

- 적중: `place == 1`
- 배당: 경주 종료 후 확정된 `plcOdds`
- 용도: 후행 검증용이며 모델 피처로는 절대 사용하지 않음

### 9.2 예상 ROI와 실현 ROI 구분

상위 퍼센트별로 다음 두 수익률을 함께 보고한다.

```text
모델 예상수익_i = calibrated_probability_i * plcOdds_i - 1
예상 ROI = mean(모델 예상수익_i)

실현수익_i = place_i * plcOdds_i - 1
실현 ROI = mean(실현수익_i)
```

- 예상 ROI는 모델의 확률을 valid에서 Platt scaling으로 보정한 후 계산한다.
- 실현 ROI는 test의 실제 입상 결과로 계산한 외부표본 성과다.
- 현재 `plcOdds`는 경주 후 확정 배당이므로, 예상 ROI는 **사후 진단용**이다. 실전 배포에는 베팅 시점의 실시간 예상 연승배당이 별도로 필요하다.
- 확률 보정 전·후의 Brier score와 calibration curve를 함께 보고한다.

상위 퍼센트별 표에는 다음 열을 포함한다.

| 상위 범위 | 베팅 수 | 적중 수 | 적중률 | Lift | 평균/중앙 연승배당 | 예상 ROI | 실현 ROI | 실현 ROI 95% CI | 최고수익 1건 제거 ROI |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 1% | | | | | | | | | |
| 2% | | | | | | | | | |
| 5% | | | | | | | | | |
| 10% | | | | | | | | | |
| 20% | | | | | | | | | |
| 30% | | | | | | | | | |
| 50% | | | | | | | | | |
| 100% | | | | | | | | | |

### 9.3 배당 품질 검사

- NaN, 문자열, 0 이하 배당 건수
- 999·999.9 등 결측 표시값 탐지
- 상위 10개 고배당 원본 행 목록
- `place == 0`인데 연승배당이 있는 것은 정상이므로 적중 배당 평균과 전체 선택 배당 평균을 구분
- 이상 고배당은 임의 삭제하지 않고 원본과 정의를 확인

### 9.4 반드시 보고할 수익 표

- 베팅 수, 적중 수, 적중률, 평균·중앙 배당
- 누적 상위 1%, 2%, 5%, 10%, 20%, 30%, 50%, 100%의 예상 ROI·실현 ROI
- 독립 점수 구간별 적중률·Lift·예상 ROI·실현 ROI
- 총 투입, 총 환급, ROI
- `race_id` 부트스트랩 95% 신뢰구간
- 최고 수익 1, 3, 5, 10건 제거 민감도
- 배당 구간별 ROI: 2배 이하, 2~3, 3~5, 5~10, 10배 초과
- 연도·분기별 ROI와 적중률
- 전체 비인기마 균등 베팅 기준선
- 시장 기대확률 기준 베팅 기준선(참고)

ROI 신뢰구간이 0을 포함하거나, 고배당 1건 제거 후 부호가 바뀌면 **수익성 미입증**으로 판정한다.

## 10. 신뢰구간과 통계 검증

### 10.1 경주 단위 부트스트랩

`race_id`를 복원추출하고, 해당 경주의 모든 말을 함께 다시 넣는다. 5,000회 반복하여 percentile 2.5%·97.5%를 보고한다.

- Lift@10% CI
- 적중률 CI
- ROI CI
- RF와 다른 모델의 paired metric difference CI

### 10.2 판정 규칙

- Lift CI 하한 > 1: 선별 신호 있음
- 모델 간 차이 CI가 0 포함: 우위 미확정, 더 단순한 모델 우선
- ROI CI가 0 포함: 수익성 미입증
- 고배당 제거 후 ROI 부호 변경: 수익성 민감, 실전 채택 불가
