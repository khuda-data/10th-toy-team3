## ⚠ `2_` 로 시작하는 둘은 초기본입니다

히스토리 보존을 위해 남겨두었습니다. **여기에는 나중에 기각된 내용이 들어 있습니다.**

| 초기본의 서술 | 최신 결론 |
|---|---|
| 다크호스 = 비인기마 **1착** | **입상(3착 이내)** — 교차검증으로 정정 (입상 100% · 1착 19.8%) |
| 배당구간 필터 = 6단계 중 유일한 성공 | **기각** — 홀드아웃 16건 · CI `[-100%, +7758%]` |
| 배당률(`q`)을 피처로 사용 | **불가** — "단승식**확정**배당"은 베팅 마감 후 확정되는 사후 정보 |

인용은 `1_준석_최신_신뢰성검증/` 에서 하세요.
