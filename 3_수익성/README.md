# 파트 2 — 시장의 빈틈과 이변 모델

파트 1에서 시장 전체를 대체하지 못한 뒤, 시장이 낮게 평가한 후보군 내부를 다시 정렬하는 문제로 전환합니다.

## 공식 기존 Test 결과

- 후보군: 인기 하위 50%
- 타깃: 3착 이내 입상
- 기준 입상률: 13.5%
- 모델 상위 10% 입상률: 24.7%
- Lift@10%: 1.82

이 결과는 후보 선별력을 지지하지만 수익성을 확정하지 않습니다. 찬진 Core 모델의 상위 10% ROI는 고배당 한 건에 민감했고 신뢰구간도 0을 포함했습니다.

## 최종 사용 원칙

- 모델의 역할은 자동 베팅이 아니라 다크호스 후보 알림입니다.
- 중요 피처는 시장이 전혀 보지 않은 정보가 아니라, 비인기마 내부에 남아 있던 조건 조합의 신호로 해석합니다.
- 준석 계보의 과거 `ROI +101.6%`는 최종 발표 수치로 사용하지 않습니다.
- 최신 백테스트의 +4.8%도 신뢰구간이 0을 포함하므로 수익 입증으로 표현하지 않습니다.
