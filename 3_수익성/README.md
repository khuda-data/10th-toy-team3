## 결과와 한계

전 구간에서는 기대우위가 음수라 공식 정책은 **`no_bet`**입니다.
다만 목표를 "1착 맞히기"에서 **"시장이 과소평가한 말 골라내기"**로 바꾸면
상위 10% 그룹의 이변 적중률이 전체 평균의 **1.81배**가 나옵니다.

**수익률 수치는 인용하지 마세요.** 세 가지 이유입니다.

1. 24개 전략 전부 신뢰구간 하한이 음수입니다
2. 개선 실험 6가지 중 5가지가 실패했습니다
3. 재현하면 숫자가 바뀝니다 — scikit-learn 버전에 민감합니다

찬진님 분석도 같은 결론에 도달했습니다 — 최고 수익 한 건을 빼면 부호가 뒤집힙니다.
