## 폴더 구조 — 보고서 4장과 같은 순서

```
data/              세 축이 공유하는 원천 데이터
0_공통/            API 수집 · 전처리 8버전 생성
1_변별력/          각도 ① 1착을 가장 잘 골라내는가
2_확률품질/        각도 ② 시장보다 정확한 확률인가
3_수익성/          각도 ③ 돈이 되는 구간이 있는가
발표자료/          파트 1 통합 보고서 · 파트 2 근거
```

세 축은 **지표도 전처리도 다릅니다.** 나란히 비교할 수 없다는 점은
파트 1 보고서 3.6절과 5.2절에 정리했습니다.

| 축 | 묻는 것 | 주 지표 | 담당 |
|---|---|---|---|
| **① 변별력** | 1착을 가장 잘 골라내는가 | ROC-AUC · PR-AUC | 박준석 · 홍정의 · 이종원 |
| **② 확률 품질** | 시장보다 정확한 확률인가 | Race Log Loss · Brier | 김찬진 |
| **③ 수익성** | 돈이 되는 구간이 있는가 | Lift · 기대우위 | 박준석 · 김찬진 |

## 바로 돌려보기

```bash
git clone -b master https://github.com/khuda-data/10th-toy-team3.git
cd 10th-toy-team3

python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS · Linux

pip install -r requirements.txt
```

| 무엇을 | 명령 | 소요 |
|---|---|---|
| 데이터 분리 | `python 0_공통/수집/02_split_by_purpose.py` | 4초 |
| 전처리 8버전 | `python 0_공통/전처리/05_make_versions.py` | 30초 |
| 각도 ① 1차 | `python 1_변별력/1차_승률모델/01_train_model.py` | 1분 |
| 각도 ① 3차 | `cd 1_변별력/3차_모델6종 && python src/train_preprocessed_models.py --model lightgbm` | 10초 |
| 각도 ② | `cd 2_확률품질 && python reproduce.py` | 수십 분 |
| 각도 ③ | `python 3_수익성/이변모델/08_full_pipeline.py` | 10초 |

> **버전을 반드시 맞춰주세요.** scikit-learn 버전이 다르면 같은 데이터·같은 시드인데도
> RandomForest 결과가 달라집니다. `requirements.txt` 상단에 근거를 적어뒀습니다.

## 발표 전에 반드시 짚을 것

**① 수익률 수치는 인용하지 않습니다.** 판별 성능은 0.3% 안에서 움직이는데 수익률은 훨씬 크게
