## 한 줄 결론

시장을 정면으로 이기는 데는 실패했습니다. 그 실패 지점에서 팀이 **세 방향으로 갈라졌고**, 셋 다 같은 결론에 닿았습니다 — 이기려면 정면이 아니라 **시장이 약한 구간**을 찾아야 합니다.

## 이야기의 뼈대

```
        승률 예측 모델 (RF, ROC-AUC 0.7495)
                    │
        배당률만으로 이미 0.817 — 우리가 진다
                    │
        피처를 20개로 줄여도 100개로 늘려도 동일
        선행 연구에도 시장을 이긴 사례가 사실상 없음
                    │
         ┌──────────┼──────────┐
       방향 A      방향 B      방향 C
    모델을 바꾼다  확률을 다듬다  구간을 고른다
      (이종원)     (김찬진)     (박준석)
```

3단계에서 무너지고 4단계에서 갈라집니다. **이 갈라짐이 발표의 축입니다.**

## 세 방향이 각각 무엇을 했나

목표가 달라서 **지표도 다릅니다.** 세 숫자를 나란히 비교할 수는 없습니다.

| | 목표를 어떻게 바꿨나 | 주 지표 | 결과 |
|---|---|---|---|
| **A** 이종원 | 안 바꿈 — 방법만 교체 | ROC-AUC | 여섯 모델 모두 0.817 못 넘음 |
| **B** 김찬진 | "1착 맞히기" → **확률의 정확도** | Race Log Loss · Brier | 점 추정으로는 이김. 신뢰구간이 못 받침 |
| **C** 박준석 | "1착 맞히기" → **시장이 틀린 말 찾기** | Lift · ROI | 중배당 구간 ROI +32.0% |

## 자료

### `1_시장이라는_벽/` — 왜 정면 승부가 막혔나

| 파일 | 이 자료가 말하는 것 |
|---|---|
| `1_승률모델_최종보고서.pdf` | RandomForest **0.7495** vs 시장 **0.817** |
| `2_비시장모델_피처실험.pdf` | 피처 20~100개, 어디를 잘라도 시장에 못 닿음 |
| `3_문헌조사.pdf` | 선행 연구에도 시장을 이긴 사례가 사실상 없음 |

**피처 개수의 문제가 아니었다**는 것이 이 세 자료의 결론입니다.

### `2_방향A_모델교체/` — 모델을 바꿔보자 (이종원)

| 순위 | 모델 | valid ROC-AUC | test ROC-AUC | 상위 10% ROI |
|---|---|---:|---:|---:|
| 3 | LightGBM rank+binary | **0.7637** | 0.7552 | +45.0% |
| 4 | CatBoost ordered | 0.7501 | 0.7508 | +13.3% |
| 5 | Random Forest | 0.7467 | 0.7507 | **+55.0%** |

여섯 모델 중 **수업에서 다룬 세 가지**만 추렸습니다. 1·2위였던 Deep listwise ensemble과
Plackett-Luce hybrid는 순위학습 계열이라 제외했고, 전체 표는 `모델6종_지표.csv`에 있습니다.

두 가지가 눈에 띕니다.

- **LightGBM은 valid 1위(0.7637)였다가 test에서 밀렸습니다.** 검증에서 좋았던 게 실전에서 유지되지 않습니다.
- **변별력 순위와 수익 순위가 어긋납니다.** CatBoost가 RandomForest보다 변별력은 높은데 ROI는 4분의 1입니다.

`모델6종_보고서.html`은 그래프가 파일 안에 들어 있어 인터넷 없이 열립니다.
GitHub에서는 소스로 보이니 내려받아 브라우저로 여시면 됩니다.

### `3_방향B_확률보정/` — 확률을 더 정확하게 (김찬진)

M2 XGBoost를 시장 확률에 **5%만** 섞고 온도 보정(T=0.95). 635경주를 **최초 1회만** 평가.

| | Race Log Loss ↓ | Top-1 적중률 |
|---|---:|---:|
| 시장 | 1.817348 | **37.80%** |
| M2 XGBoost | **1.813446** | 37.48% |

점 추정으로는 두 지표 모두 시장을 이겼습니다. 그런데 부트스트랩 5,000회에서
**Log Loss만 신뢰구간 하한이 0을 넘었고 Brier는 넘지 못했습니다.** 작성자 본인의 결론도
"두 주 지표 모두에서 통계적으로 뒷받침되지는 않는다"입니다.

개선폭 0.0039는 공제율 약 20%를 넘기에 턱없이 작아, 베팅 정책은 `no_bet`입니다.

### `4_방향C_이변필터/` — 시장이 약한 구간만 (박준석)

RandomForest로 "시장이 과소평가한 말"을 고르고, **winOdds 10~50배 구간의 상위 10%**만 단승.

| | |
|---|---|
| ROI | **+32.0%** |
| 베팅 / 적중 | 237건 / 22건 (9.28%) · 평균 배당 15.1배 |
| 부트스트랩 1,000회 | **87.9%에서 수익** |
| 95% 신뢰구간 | [−23.4, +83.1] |

`배당구간별_ROI.csv`에 24개 조합이 전부 있습니다. ROI 최고는 사실 10~30배 상위 5%의
**47.8%**인데, 베팅이 68건뿐이라 신뢰구간이 [−47.2, +153.1]로 훨씬 넓습니다.
10~50배 10%를 고른 것은 **수익 확률이 가장 높고 표본이 충분해서**입니다.

`개선실험_결과.csv`는 시도한 개선 6가지 중 **5가지가 실패**했음을 보여줍니다 (ROI −7~−15%).
`로버스트니스_검증.csv`는 고배당 적중을 하나씩 빼면 5개 조건 모두 음수가 된다는 기록입니다.

## 발표 전에 반드시 짚을 것

**24개 전략 전부 신뢰구간 하한이 음수입니다.** 통계적으로 수익이 확정된 전략은 하나도 없습니다.
"ROI +32%"만 내세우면 질문받을 때 방어가 안 됩니다.

**모델 6종의 ROI는 베팅 64건 기준입니다.** 순위가 표본 하나에 흔들릴 수 있는 규모입니다.

**부경 데이터로는 검증하지 않았습니다.** 서울 32,888행만 썼습니다.

이 셋을 먼저 말하면 나머지 주장이 오히려 단단해집니다.
