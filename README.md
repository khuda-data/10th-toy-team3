## 왜 이 주제인가

경마는 **대중의 예측이 실시간으로 집계되어 숫자로 공개되는** 몇 안 되는 도메인입니다. 배당률이 그 숫자입니다.

일반적인 예측 문제에서는 모델의 성능을 "정답을 얼마나 맞혔나"로만 잽니다. 그런데 경마에는 **비교 대상이 이미 존재합니다.** 수만 명이 자기 돈을 걸어 만들어낸 확률 추정치가 매 경주마다 공개되기 때문입니다.

그래서 이 프로젝트는 두 가지를 동시에 묻습니다.

1. 말·기수·조교사·훈련 데이터로 1착 확률을 얼마나 잘 예측할 수 있는가
2. 그 예측이 **배당률이라는 기준선을 넘는가**

두 번째 질문이 이 프로젝트를 다른 예측 과제와 구분 짓는 지점입니다.

## 문제 정의

### 예측 대상

각 출전마의 **1착 여부** (`win`). 경주당 평균 10.4두가 출전하므로 양성 비율이 약 9.6%로 불균형이 큽니다.

### 기준선 — 배당률

한국 경마는 **파리뮤추얼(pari-mutuel)** 방식입니다. 참가자들이 낸 돈을 모아 주최측 몫을 뗀 뒤 맞힌 사람끼리 나눕니다. 즉 배당률은 주최측이 매긴 가격이 아니라 **사람들이 어디에 얼마를 걸었는지의 결과**입니다.

배당률을 확률로 뒤집으면 시장이 보는 승률이 나옵니다.

```
암묵 확률 = 1 / 배당률
시장 확률 q = (1/O) / S ,   S = 경주 내 모든 말의 1/O 합
```

한 경주의 `1/배당률`을 다 더하면 1이 아니라 약 1.25가 나옵니다. 주최측이 미리 떼어간 몫 때문입니다. 이 값을 **오버라운드 S**라 부르며, 우리 데이터의 경주별 중앙값은 **1.2496** 입니다. 즉 환급률이 약 80%입니다.

### 이 프로젝트의 핵심 제약

모델은 **현재 경주의 배당·베팅금액·인기 정보를 쓰지 않습니다.** 시장과 독립적으로 예측해야 비교가 성립하기 때문입니다. 어떤 열이 여기 해당하는지는 [`docs/데이터.md`](docs/데이터.md)에 정리했습니다.

## 접근 방법

```
[KRA API 11종]
      │  collect
      ▼
[raw/ 원본 JSON]
      │  전처리 · 확장창 집계 · 누수 감사
      ▼
[final.csv.gz  56,648 × 156]
      │  서울 필터 · 결측/이상치 처리 · 스케일링 8버전
      ▼
[전처리 데이터셋/ v1~v8]
      │  시간순 분할
      ▼
[모델 학습]  ──▶  [시장 기준선과 비교]
```

### 피처 설계 원칙

- **확장창(expanding window)** — 말·기수·조교사·마주의 누적 성적은 **직전 경주까지만** 집계합니다. 오늘 결과가 오늘의 피처에 들어가지 않게 합니다
- **경주 내 상대화** — 출주두수가 6~16으로 변하므로 절대값 대신 경주 내 z점수(`__z`)와 백분위(`__pr`)를 함께 만듭니다
- **구조적 결측 보존** — 첫 출전마에게 과거 성적이 없는 것은 결측이 아니라 정보입니다. 0으로 채우되 플래그를 남깁니다

### 모델

경주 단위로 확률의 합이 1이 되도록 맞추는 것을 원칙으로 합니다. 현재까지 비교한 계열은 다음과 같습니다.

| 계열 | 사용 모델 |
|---|---|
| 선형 | 로지스틱 회귀 |
| 트리 앙상블 | Random Forest, XGBoost, LightGBM, CatBoost |
| 랭킹 학습 (LTR) | LightGBM LambdaRank, Plackett-Luce |
| 신경망 | Deep listwise ensemble |

### 2. 데이터 불러오기

모델에 따라 알맞은 버전을 고르면 됩니다.

```python
import pandas as pd

VERSION = "v1_base"          # 트리 모델(RF, XGBoost, LightGBM)
# VERSION = "v2_standard"    # 로지스틱 회귀, SVM
```
