# 시장이라는 벽, 그리고 시장의 빈틈

KHUDA 10기 토이프로젝트 3조의 **최종 발표·분석 전용 `master` 브랜치**입니다.

`main`은 전체 연구 이력과 자동 생성 산출물을 보존합니다. `master`에는 최종 발표 스토리와 직접 연결되는 데이터, 코드, 결과표, 근거자료만 정리합니다.

## 최종 질문

> 배당률을 입력하지 않은 독립적인 데이터 모델이 시장의 집단 예측보다 더 정확할 수 있는가?

파트 1에서는 시장을 대체하는 독립 모델을 만들었고, 변별력과 확률 품질 모두에서 시장을 넘지 못했습니다. 파트 2에서는 질문을 바꿔 시장이 낮게 평가한 말들 내부에서 실제 입상 후보를 다시 선별했습니다.

## 최종 결론

- 독립 모델은 누가 유력한지 시장보다 잘 구분하지 못했습니다.
- 독립 모델은 각 말의 승리 확률도 시장보다 정확하게 표현하지 못했습니다.
- 다크호스 모델은 인기 하위 50% 내부에서 입상 후보를 압축했습니다.
- 기존 잠금 Test의 기준 입상률은 13.5%, 모델 상위 10% 입상률은 24.7%, Lift@10%는 1.82였습니다.
- 2026-08-10~2026-08-23 최신 서울 경마에서는 이변예측 모델이 25건 중 6건을 적중해 24.0%의 입상률을 기록했습니다.
- 최신 이변예측 ROI는 +4.8%였지만 95% 신뢰구간이 [-66.8%, +93.2%]이므로 수익성은 입증되지 않았습니다.

## 발표에서 사용하는 모델

### 파트 1 변별력

- LightGBM
- CatBoost
- Random Forest
- XGBoost

Deep Listwise와 Plackett–Luce는 최종 발표 비교에서 제외했습니다.

### 파트 1 확률 품질

- Logistic Regression
- XGBoost
- Sum Normalization
- Race Log Loss, Race Brier Score

시장 확률을 모델 입력 또는 앵커로 사용한 후속 보정 성과는 최종 독립 모델 결론에 포함하지 않습니다.

### 파트 2

- 후보군: 인기 하위 50%
- 타깃: 3착 이내 입상
- 주 모델: Random Forest
- 중심 지표: Lift@10%
- 모델 역할: 자동 베팅이 아니라 다크호스 후보 스크리닝

## 수치 인용 원칙

1. `upset_B`는 비인기마 1착이 아니라 **인기 하위 50% 중 3착 이내 입상**입니다.
2. 기존 Test의 대표 결과는 기준 입상률 13.5%, 상위 10% 입상률 24.7%, Lift 1.82입니다.
3. 최신 백테스트의 +4.8%는 양의 점추정치일 뿐 통계적으로 유의한 수익이 아닙니다.
4. 기존 문서의 `ROI +101.6%`는 최종 발표 근거로 사용하지 않습니다.
5. 모델 중요도는 연관성·선별 신호이며 인과효과로 해석하지 않습니다.

## 근거 감사에서 확인된 보완 사항

- 사용자가 확정한 [`최종_스토리라인.md`](발표자료/최종_발표/최종_스토리라인.md)는 원문 그대로 보존했습니다.
- v1 데이터는 총 111열입니다. 타깃·식별·분할 4열과 당일 시장 관련 7열을 모두 제외하면 엄격한 비시장 피처는 100개입니다. 발표문의 `102개`는 시장 관련 `gap_h`, `gap_d`를 남긴 계산과 대응하므로, 발표 전에 정의를 하나로 통일해야 합니다.
- 기존 v5 4모델 묶음에는 `winAmt`, `plcAmt`, `totalAmt` 등 당일 발매금액 파생변수가 포함돼 있었습니다. 해당 묶음은 `master`에서 제외했으며, 엄격한 비시장 4모델 수치는 [`재실행 계약`](1_변별력/3차_4모델비교_재실행필요/README.md)에 따라 다시 만들어야 합니다.
- 확률 품질은 시장 혼합·보정 뒤 수치가 아니라 Logistic·XGBoost 독립 모델의 Final Test 수치만 별도 보존했습니다. 두 독립 모델 모두 시장보다 Race Log Loss와 Race Brier가 높았습니다.
- 최신 서울 51경주 결과는 제공된 보고서와 요약표를 보존했지만, 경주별 원시 예측·정산 행과 실행 코드가 저장소에 없어 완전 재현 자료는 아닙니다.
