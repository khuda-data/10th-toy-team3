# 10th-toy-team3 · 발표용

**배당률이라는 대중의 집단 예측을 데이터 모델이 넘어설 수 있는가**

KHUDA 10기 토이프로젝트 3조 · 한국마사회 서울 경주 2023.08 – 2026.08

> 발표 자료와 **그 결과를 직접 재현할 수 있는 코드·데이터**만 담았습니다.
> 전체 실험 기록과 코드는 [`main` 브랜치](../../tree/main)에 있습니다.

## 파트 1 — 시장이라는 벽

[`발표자료/파트1_시장이라는_벽/`](발표자료/파트1_시장이라는_벽)

통합 보고서 한 권(38쪽)에 데이터셋 구축부터 인사이트까지 전부 담았습니다.

| 절 | 내용 |
|---|---|
| 1 | 왜 경마인가 — 파리뮤추얼 · 오버라운드 · 공제율 |
| 2 | 데이터 — API 11종 · 56,648행 × 156열 · 누수 방지 3원칙 |
| 3 | 전처리 — 결측 · 이상치 · 다중공선성 · 시간순 분할 |
| 4 | **세 각도의 도전** — 변별력 · 확률 품질 · 수익성 |
| 5 | 결과 — 셋 다 벽에 부딪혔다 |
| 6 | 문헌조사 — 남들은 어땠나 |
| 7 | 왜 이기지 못하는가 — 여덟 개의 벽 |
| 8 | 인사이트 — 질문을 바꾼다 |

`근거자료/`에 원본 보고서 4편(승률모델 · 비시장모델 · 시장확률보정 · 문헌조사)이 있습니다.
발표 중 질문받으면 원본을 열어 보여줄 수 있습니다.

### 세 각도가 각각 무엇을 했나

목표가 달라서 **지표도 전처리도 다릅니다.** 세 결과를 나란히 비교할 수는 없습니다.

| | 묻는 것 | 주 지표 | 결과 |
|---|---|---|---|
| **① 변별력** | 1착을 가장 잘 골라내는가 | ROC-AUC · PR-AUC | 시장 0.8126 · 최고 0.7552 — **미달** |
| **② 확률 품질** | 시장보다 정확한 확률인가 | Race Log Loss · Brier | Log Loss만 통과 — **부분 달성** |
| **③ 수익성** | 돈이 되는 구간이 있나 | 기대우위 | 최대 −3.47% — **미달 · `no_bet`** |

## 바로 돌려보기

```bash
git clone -b master https://github.com/khuda-data/10th-toy-team3.git
cd 10th-toy-team3

python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS · Linux

pip install -r requirements.txt
```

```bash
python src/4_이변모델/08_full_pipeline.py          # 약 10초
python src/5_이변모델_선정/02_final_strategy.py     # 약 6초
```

결과는 `results/` 아래에 생깁니다. 저장소에는 올리지 않습니다.

> **버전을 반드시 맞춰주세요.** scikit-learn 버전이 다르면 같은 데이터·같은 시드인데도
> RandomForest 결과가 달라집니다. 자세한 내용은 `requirements.txt` 상단에 있습니다.

## 발표 전에 반드시 짚을 것

**① 수익률 수치는 인용하지 않습니다.** 판별 성능은 0.3% 안에서 움직이는데 수익률은 훨씬 크게
흔들립니다. 결론이 고배당 적중 한두 건에 좌우된다는 뜻입니다. 근거는 파트 1 보고서 8.1절에 있습니다.

**② 세 각도의 숫자를 나란히 비교하지 마세요.** 지표도 전처리도 다릅니다. 애초에 다른 데이터로
학습한 다른 모델입니다.

**③ 부경 데이터로는 검증하지 않았습니다.** 서울 32,888행만 썼습니다.

이 셋을 먼저 말하면 나머지 주장이 오히려 단단해집니다.
