# 학습 · 검증 · 평가 분할 안내

`data/전처리_데이터셋/` 아래 8개 버전이 **어떻게 나뉘어 있는지**와 **어떻게 불러 쓰는지**를 정리한 문서입니다.

생성일 2026-08-16 · 마지막 갱신 2026-08-22

---

## 분할 방식

**경주일 순서대로 60 : 20 : 20으로 잘랐습니다.** 무작위로 섞지 않았습니다.

경마는 시간이 흐르면서 말도 기수도 바뀌고 시장의 정확도도 달라집니다. 데이터를 섞어서 나누면 **미래 경주로 학습해 과거 경주를 맞히는** 상황이 되고, 실전에서는 불가능한 조건이라 성능이 부풀려집니다.

- `rcDate`(경주일) 오름차순으로 정렬한 뒤 경계를 잡았습니다
- 경계는 **경주일 단위**로 떨어집니다. 같은 경주가 두 집합에 걸치는 일은 없습니다
- 대상은 **서울 경마장**입니다 (부경 제외)

---

## 분할 크기

8개 버전 모두 같은 경계를 씁니다. 다만 이상치를 제거한 v5~v8은 행이 줄어듭니다.

| 구분 | 행 수 | 비율 | 1착 비율 | 경주일 범위 |
|---|---:|---:|---:|---|
| train | 19,637 | 59.7% | 9.65% | 2023-08-05 ~ 2025-05-11 |
| valid | 6,591 | 20.0% | 9.76% | 2025-05-17 ~ 2025-12-27 |
| test | 6,660 | 20.3% | 9.56% | 2025-12-28 ~ 2026-08-09 |
| **합계** | **32,888** | 100% | | |

세 구간의 1착 비율이 9.5~9.8%로 거의 같습니다. 시간순으로 잘랐는데도 난이도가 한쪽으로 쏠리지 않았다는 뜻이라, 비교 기준으로 쓰기에 무리가 없습니다.

```
├── v4_robust/                 이상치 포함 · RobustScaler
├── v5_base_no_outlier/        이상치 제거 · 스케일링 없음
├── v6_standard_no_outlier/    이상치 제거 · StandardScaler
├── v7_minmax_no_outlier/      이상치 제거 · MinMaxScaler
└── v8_robust_no_outlier/      이상치 제거 · RobustScaler
```

버전별 차이와 어떤 모델에 무엇을 쓸지는 ``reports/1_전처리/03_버전가이드.docx``에 자세히 나와 있습니다.

**모르겠으면** — 트리 모델(랜덤포레스트·XGBoost·LightGBM)은 `v1_base`, 로지스틱 회귀·SVM은 `v2_standard`를 쓰면 됩니다.

> **v5~v8은 모델 입력으로 쓰지 마세요.** 이상치를 행 단위로 지웠기 때문에 같은 경주에서 일부 출전마만 남습니다. 경주 안의 확률 합이 1이 되어야 하는 구조가 깨지므로, 확률 평가나 백테스트에 쓰면 결과가 틀립니다. 표본도 크게 줄어서 `v8_robust_no_outlier`의 test는 89행뿐입니다.
>
> v1~v4도 신규 파이프라인의 입력은 아닙니다. 과거 보고서 수치를 확인할 때만 씁니다. 자세한 정책은 [`사용정책.md`](사용정책.md)에 있습니다.

## 불러오는 법

`.gz`로 압축돼 있지만 pandas가 알아서 풀어 읽습니다.

```python
import pandas as pd

VERSION = "v1_base"          # 트리 모델
# VERSION = "v2_standard"    # 로지스틱 회귀 · SVM
# VERSION = "v3_minmax"      # KNN · K-means

BASE = f"data/전처리_데이터셋/{VERSION}"
dtypes = {"hrNo": str, "jkNo": str, "trNo": str, "owNo": str}

train = pd.read_csv(f"{BASE}/train.csv.gz", encoding="utf-8-sig", dtype=dtypes)
valid = pd.read_csv(f"{BASE}/valid.csv.gz", encoding="utf-8-sig", dtype=dtypes)
test  = pd.read_csv(f"{BASE}/test.csv.gz",  encoding="utf-8-sig", dtype=dtypes)

y_train = train["win"]
```

**피처에서 빼야 할 열**(식별자 · 경주 결과 · 배당 정보)의 목록은 [`src/1_전처리/config.py`](../../0_공통/전처리/config.py)에 정의돼 있습니다.

## 쓸 때 지킬 것

**`hrNo` 같은 식별자는 문자열로 읽으세요.** 숫자로 읽으면 앞자리 0이 사라져서 조인이 깨집니다. 위 예시의 `dtypes`가 그 역할을 합니다.

**valid와 test의 역할이 다릅니다.** valid는 하이퍼파라미터와 임계값을 고를 때 씁니다. test는 **최종 보고 한 번만** 봅니다. test를 보고 설정을 바꾸면 그 숫자는 더 이상 믿을 수 없게 됩니다.

**`fold` 열이 남아 있습니다.** 이미 파일이 나뉘어 있으니 중복 정보이고, 피처로 넣으면 안 됩니다.

**인코딩은 `utf-8-sig`입니다.** 엑셀에서 한글이 깨지지 않게 하기 위한 것이라, 읽을 때도 같은 값을 지정해야 합니다.
