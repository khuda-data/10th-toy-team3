## 시작 전에 꼭 읽을 것

[`데이터.md`](데이터.md)의 「쓸 때 지킬 것」 절입니다. 아래 다섯 가지를 놓치면 결과가 **조용히** 틀립니다 —
오류가 나지 않고 그럴듯한 숫자가 나오기 때문에 나중에 알아채기 어렵습니다.

| | |
|---|---|
| 1 | `hrNo` 등 식별자는 **문자열로** 읽기. 숫자로 읽으면 앞자리 0이 날아가 조인이 깨집니다 |
| 2 | 경주 **결과·사후 정보**를 피처에 넣지 않기 |
| 3 | 현재 경주의 **배당·베팅 정보**를 피처에 넣지 않기. 이 프로젝트의 핵심 제약입니다 |
| 4 | **시간순 분할** 지키기. `train_test_split`으로 섞으면 안 됩니다 |
| 5 | `class_weight`·오버샘플링 쓰지 않기. 확률 자체가 분석 대상이라 보정이 무너집니다 |

코드에서 이 제약을 강제하는 장치가 `config.py` 의 `EXCLUDE_COLS` 입니다 —
식별자·시장·결과 열을 모두 합집합으로 묶어 두었고, `get_feature_cols(df)` 가 그걸 빼고 돌려줍니다.

데이터가 어떤 단계를 거쳐 만들어지는지는 [`../data/README.md`](../data/README.md)에 있습니다.
