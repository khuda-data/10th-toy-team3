## ⚠ 주의 세 가지

**① NDCG 는 비교하지 마세요.**

원본 패키지에 학습 코드가 없어 `model_manifest.json` 의 피처·타깃·설정만으로 재구성했는데,
NDCG 의 relevance·gain 정의는 복원하지 못했습니다. 같은 예측이라도 gain 방식(선형 vs 지수)에 따라
NDCG@1 이 0.83 과 0.40 사이를 오갑니다.

이 폴더의 `metrics.json` 에도 NDCG 가 들어 있지만 **원본 수치와 같은 눈금이 아닙니다.**
Top-1 · Spearman · Kendall · 쌍별 정확도처럼 **정의가 하나뿐인 지표만** 비교했습니다.

**② 재학습이지 재현이 아닙니다.**

원본의 전처리 파이프라인(`revised_v11_seoul_bugyeong_rank_clean_preprocessed`)이 저장소에 없습니다.
원-핫·타깃 인코딩·결측 지시자를 manifest 의 피처 이름에서 역추적해 다시 만들었으므로,
같은 데이터를 넣어도 원본과 완전히 같은 값이 나오지는 않습니다.

**③ `te_*` 는 train 에서만 적합했습니다.**

`te_jkName` · `te_trName` · `te_owName` · `te_rank` 는 타깃 인코딩입니다.
valid·test 를 포함해 적합하면 누수가 되므로 **train 구간만으로 평균을 내고 스무딩(k=20)** 을 걸었습니다.

참고로 `te_rank` 의 `rank` 는 착순이 아니라 **경주 등급**(1등급 · 국OPEN 등)입니다. 누수가 아닙니다.
