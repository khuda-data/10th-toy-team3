1. 지표와 산식 — 먼저 읽는 해설

1.1 시장확률, 모델확률, EDGE

qᵢ = (1 / oddsᵢ) / Σⱼ(1 / oddsⱼ)    |    Σᵢqᵢ = 1
EDGEprob,i = pᵢ − qᵢ    |    EDGEEV,i = pᵢ × dividendᵢ − 1

q는 한 경주 안에서 역배당을 정규화한 시장의 승리확률, p는 모델의 승리확률입니다. 확률 EDGE는 둘의 차이이고, 기대수익 EDGE는 실제 예상 환급배당까지 곱합니다. Benter는 기대수익이 1보다 큰 티켓을 advantage bet으로 설명했습니다.[R1]

EDGE — 시장이 반영한 확률과 모델이 추정한 공정확률 사이의 차이입니다. EDGE가 양수라는 사실만으로 수익이 보장되지는 않습니다. 확률오차·공제·가격변화·자기 주문의 가격충격이 모두 남습니다.

복승·쌍승·삼복승·삼쌍승·복연승은 말별 단승 확률로 Plackett–Luce/Harville형 조합확률을 만들었습니다. Benter도 기본 Harville의 2·3착 편향을 경고하고 별도 보정을 제시했습니다.[R1] 현재 프로젝트의 복합승식 EDGE는 실제 조합시장별 사전 확률이 아니라 대용 확률입니다.

Plackett–Luce / Harville — 1착 확률을 조건부로 재정규화해 2착·3착 순서를 만드는 근사입니다. 실제 조합 풀의 참가자 선호와 구조를 직접 관측한 값이 아닙니다.

1.2 로그손실과 ΔLL

LLmodel = −(1/R) Σᵣ log pᵣ,winner
ΔLL / race = (1/R) Σᵣ [log pᵣ,winner − log qᵣ,winner]

로그손실은 실제 승자에게 준 확률이 작을수록 큰 벌점을 줍니다. 여기서 ΔLL은 시장 대비 모델이 승자에게 얼마나 더 좋은 확률을 줬는지 나타내며, 양수일수록 모델이 시장보다 정보가 많습니다. 이것은 ROI와 다른 지표입니다.

ΔLL/경주 — 시장과 모델의 로그확률 차이를 경주별 평균한 값입니다. +0.01은 “1%p 정확도 향상”을 뜻하지 않습니다. 확률분포 전체의 정보량 개선이며 직접적인 원화 수익이 아닙니다.

2. Benter 접근법 — 시장을 버리지 않고 시장의 오차만 찾기

Benter 보고서의 요지는 “내 모델 대 시장”의 단순 대결이 아닙니다. 공개정보 기반 기본모형이 놓친 내부·집단 정보를 시장배당에서 회수하고, 두 확률을 결합해 보정된 확률을 만든 뒤, 수익과 자금 크기를 함께 최적화하는 것입니다.[R1]

Sugiura는 2015–2022 학습, 2023–2024 검증, 2025-01-05~2026-05-10 독립 테스트로 나눴습니다. 테스트 4,556경주에서 ROC AUC .6459, PR-AUC .6308, Brier .2325, ECE-10 .0213이었고, 이변확률 상위 10% 경주의 실제 이변률은 .6820(전체 .5151), 하위 10%는 .2193이었습니다.[R7]

Abstention / 선택적 예측 — 모든 경주에 베팅하지 않고 모델이 불안정하거나 시장과 차이가 불명확한 경주는 건너뛰는 정책입니다.

10.3 새로 추가할 운영 지표

Closing Line Value

의사결정 시점 배당과 최종배당의 차이. 양의 CLV가 있어야 주문 시점 우위를 점검할 수 있습니다.

Capacity

pool 대비 stake와 예상 배당하락. Kelly가 커도 시장이 받아주지 못하면 실행할 수 없습니다.

Tail dependence

총수익 중 상위 환급 1·5·10건 비중과 제거 ROI. 고배당 우연 의존을 드러냅니다.

Cost-adjusted risk

운영비·세금·지연 후 Sharpe, Sortino, CVaR, MDD를 함께 봅니다.

Calibration drift

주·월별 Brier/ECE/ΔLL 변화. 시장이 학습하거나 계절이 바뀌는지를 추적합니다.

Crowding sensitivity

다른 CAW가 같은 신호를 쓸 때 EDGE가 얼마나 빨리 사라지는지 스트레스 테스트합니다.

12. 중간 결론

시장 앵커 방향은 유지할 가치가 있지만 증거 범위를 서울·clean 133피처로 축소해야 합니다. 최신 clean 테스트에서 ΔLL 개선이 확인됐기 때문입니다. 137피처 착순·앵커 결과는 최종 pool 4개 때문에 배치 근거에서 제외하며, 부경 성능은 아직 재학습하지 않았습니다.

유지: 경주 단위·시계열 분할, odds 비피처 원칙, 시장 q 앵커, Base Margin, 확률합 1, 공식환급·해시·재로딩 검증, 최종 pool 4개 제외.
보류: 2개 이변 피처 재학습 모델, 상위 10~40% 점추정 고수익 셀, 검증에서만 높았던 복합승식 정책.
먼저 해결: 서울+부경 clean 133피처 재학습, 의사결정 시점 배당, 실제 조합시장 가격, 신규 OOS, 가격충격·capacity, 비용 후 fractional Kelly.

현재 단계의 정직한 한 줄 결론: “서울 데이터의 clean 133피처에서 시장 확률오차를 조금 설명했지만, 부경 재현과 수수료 후 반복 가능한 수익은 아직 검증되지 않았다.”
