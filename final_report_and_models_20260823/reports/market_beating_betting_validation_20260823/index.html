기존 v11 저장 예측을 이용한 validation 선택 → test 고정 비교

결론

시장보다 더 정확한 확률 방법은 확인됐다. validation에서 선택된 시장 앵커 Base Margin은 test Log Loss를 시장보다 개선했다. 그러나 절대 수익이 확인된 베팅 방법은 없다. 시장 선택보다 적중/ROI가 나은 게이트가 있더라도 공제 후 양의 절대 ROI와는 다른 주장이다.

1. 지표

  • ΔLL: 시장 Log Loss − 모델 Log Loss. 양수면 모델이 시장보다 정확하다.
  • 동일경주 적중률 차이: 선택된 같은 경주에서 모델 티켓 적중률 − 시장 티켓 적중률.
  • 동일경주 ROI 차이: 모델 티켓 ROI − 시장 티켓 ROI. 시장보다 덜 잃어도 양수가 될 수 있다.
  • 절대 수익: 모델 ROI의 95% CI 하한이 0보다 큰 경우만 확인으로 인정한다.

4. 해석 제한

8~15배 과거 결과는 참고로만 남기고 이번 정책 선택에는 사용하지 않았다. 현재 test는 이미 이전 작업에서 관찰됐다. 복합승식 시장확률은 실제 낙첨 조합의 사전 pool 가격이 아니라 q 파생 근사이며, closing odds도 실시간 주문가격이 아니다. 따라서 이 보고서는 기존 결과의 정리·재검증이지 새 미래 확증이 아니다.

5. 실행 가능한 최소 방법

  1. 시장 앵커 Base Margin으로 시장 승리확률을 보정한다.
  2. 승식별 validation 잠금 게이트만 적용하고 나머지는 no_bet한다.
  3. 시장보다 나은 적중/ROI 차이와 절대 수익을 분리한다.
  4. 새 미래 OOS에서 절대 ROI CI 하한이 0을 넘기 전까지 실전 베팅하지 않는다.
