# 3차 모델링 — 모델 비교

프로젝트 흐름 **3단계**. 배당률에서 뽑은 시장 확률을 어떻게 다루느냐에 따라 여러 모델을 만들어 비교하고,
가장 나은 LightGBM을 경주 단위 5-fold로 다시 검증한 결과입니다.

작성 이종원 (`happy97908a-cmyk`)

## 후보에서 제외한 모델 둘

원래 실험은 여섯 모델이었습니다. 이 저장소가 후보로 다루는 것은 **넷**입니다.

| 제외한 모델 | 계열 | 원래 성적 |
|---|---|---|
| Deep listwise ensemble | 딥러닝 | test ROC-AUC 0.7710 (1위) · 상위 10% ROI **−8.6%** |
| Plackett-Luce hybrid | 순위학습 | test ROC-AUC 0.7684 (2위) · 상위 10% ROI +23.3% |

변별력 순위로는 1·2위였지만 둘 다 프로젝트가 다루기로 한 범위 밖입니다.
**변별력 1위가 수익 최하위**였다는 점은 그대로 기록해 둘 만합니다 — 이 프로젝트 전체를 관통하는
"ROC-AUC 순위와 수익 순위는 어긋난다"는 관찰의 가장 뚜렷한 사례입니다.

지표 CSV 네 개는 4종만 담도록 다시 계산했습니다. 원본 6종 수치는 `main` 브랜치와 커밋 `7f90843`에 있습니다.

> **`v5_final_model_report.html`은 예외입니다.** 그래프가 이미지로 박혀 있어 4종으로 다시 그리려면

## 파일

파일명이 영문인 것은 생성 코드가 이 이름 그대로 쓰기 때문입니다. 아래가 한글 대응입니다.

| 파일 | 무엇인가 | 범위 |
|---|---|---|
| `v5_final_model_report.html` | 최종 보고서 전문 + 모든 시각자료 | 6종 (원본) |
| `v5_model_metrics.csv` | 공통 최종 지표 (ROC-AUC · ROI 등) | 4종 |
| `v5_model_detail_metrics.csv` | 위를 train · valid · test로 나눈 상세 지표 | 4종 |
| `v5_general_model_threshold_comparison.csv` | EDGE 상위 10% · 20% · 30%로 잘랐을 때의 비교 | 4종 |
| `v5_feature_importance_consensus.csv` | 모델들이 공통으로 중요하다고 본 피처 | 4종 |
| `v5_lightgbm_5fold_results.csv` | LightGBM 경주 단위 5-fold 각각의 결과 | LightGBM |
| `v5_lightgbm_5fold_summary.json` | 위 5-fold의 평균 · 표준편차 · OOF 요약 | LightGBM |

`v5`는 이 실험에서 쓴 데이터셋 판번호입니다. `data/전처리_데이터셋/`의 v1~v8과는 다른 체계입니다.

### 4종 기준으로 다시 계산한 것

`v5_feature_importance_consensus.csv`의 `mean_rank_score` · `rank_score_std` · `consensus_rank`는
남은 네 모델만으로 다시 집계했습니다. 그 결과 **합의 1위가 `hr_last_ord`에서 `age__pr`로 바뀝니다.**

`top20_models`(그 피처를 상위 20위 안에 둔 모델 수)는 원본 판정에서 제외한 두 모델의 몫만 뺐습니다.
원본 생성 규칙이 경계에 걸린 행 하나에서 재현되지 않아, 규칙을 추측해 전부 다시 매기는 대신
**남은 네 모델의 원래 판정을 그대로 보존**하는 쪽을 택했습니다.

## 결과 요약

| 순위 | 모델 | valid ROC-AUC | test ROC-AUC | 상위 10% ROI |
|---|---|---:|---:|---:|
| 1 | LightGBM rank+binary | **0.7637** | 0.7552 | +45.0% |
| 2 | CatBoost ordered | 0.7501 | 0.7508 | +13.3% |
| 3 | Random Forest | 0.7467 | 0.7507 | **+55.0%** |
| 4 | XGBoost | 0.7415 | 0.7419 | **+55.0%** |

**ROC-AUC 순위와 수익 순위가 뒤집힙니다.** 가장 잘 맞히는 모델이 가장 많이 버는 모델은 아니었습니다.
다만 베팅 표본이 64건뿐이라 ROI 수치는 아직 흔들립니다.

**LightGBM은 valid 1위였다가 test에서 밀렸습니다.** 검증에서 좋았던 것이 실전에서 유지되지 않습니다.

네 모델 모두 시장의 ROC-AUC 0.817에는 닿지 못했습니다. 제외한 두 모델도 마찬가지였습니다.
