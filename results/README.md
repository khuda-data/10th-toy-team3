# results/ — 코드가 실행 결과를 쌓는 곳

이 폴더는 **비어 있는 것이 정상**입니다. `src/`의 스크립트가 그림·지표 CSV·중간 모델을 여기에 씁니다.
결과물은 저장소에 올리지 않습니다 — 원본과 코드가 있으면 다시 만들어지고, 매 실행마다 바뀌기 때문입니다.

발표·공유용으로 확정된 산출물만 `reports/` 로 옮겨 담습니다.

## 어떤 스크립트가 어디에 쓰나

| 하위 폴더 | 만드는 코드 |
|---|---|
| `eda/` | `src/1_전처리/01~04` |
| `analysis/` | `src/1_전처리/버전비교/01` |
| `models/` | `src/2_승률모델/`, `src/3_시장대조/방향실험/` |
| `upset_with_odds/` | `src/4_이변모델/01~07` |
| `upset_with_odds_v2/` | `src/4_이변모델/08~10` |
| `upset_improvements/` | `src/5_이변모델_선정/01~03`, `05` |
| `upset_insights/` | `src/5_이변모델_선정/04` |

경로는 각 `config.py` 의 `RESULTS_DIR` · `MODELS_DIR` 상수에서 옵니다.
