# 방향 실험 — 시장을 따라잡으려는 세 가지 시도

2단계에서 시장(배당률)이 모델보다 정확하다는 게 확인된 뒤, 그 격차를 좁혀보려고 던진 세 가지 방향입니다.

번호가 곧 방향 번호입니다 — `01`이 방향 1, `02`가 방향 2, `03`이 방향 3이고, `04`는 세 결과를 한데 모아 보고서로 만드는 코드입니다.

**전제 조건** — 세 방향 모두 [`src/2_승률모델/01_train_model.py`](../../2_승률모델/01_train_model.py)로 학습해둔 RandomForest 모델(`results/models/`)을 불러와서 시작합니다.

## 코드 설명

| 파일 | 설명 | 산출물 | 작성자 |
|---|---|---|---|
| `01_calibration.py` | 방향 1 — 기존 RandomForest 모델의 예측 확률을 Platt Scaling(시그모이드)·Isotonic Regression으로 보정해, 실제 승률에 더 가까워지는지 검증 | `results/v1_calibration/` → `v1_report.html` (확률 보정 실험) | 박준석 (junseok) |
| `02_stacked.py` | 방향 2 — 1단계 모델의 예측확률과 배당률에서 뽑은 시장확률(q)을 결합한 2단계 모델을 만들어, 시장보다 나은 확률 추정이 가능한지 검증 | `results/v2_stacked/` → `v2_report.html` (시장 결합 실험) | 박준석 (junseok) |
| `03_upset.py` | 방향 3 — 목표를 "1착 맞히기"에서 "시장이 틀리는 경우 찾기"로 바꿔, 비인기마(`pop_pct >= 0.5`)의 1착(`upset_B`)을 예측하는 모델 검증 | `results/v3_upset/` → `v3_report.html` (이변 예측 실험) | 박준석 (junseok) |
| `04_reports_v123.py` | v1~v3 결과를 각각 보기 좋은 HTML로 재생성 (그래프 영문화, 피처명 한글 설명 변환, 쉬운 말 설명 추가) | `v1_report.html`, `v2_report.html`, `v3_report.html` | 박준석 (junseok) |
| `config.py` | 컬럼 분류·유틸리티 함수 등 파이프라인 공통 설정 모듈 (팀 공용 설정. 각 파이프라인이 독립 실행되도록 같은 파일을 폴더마다 복사해 뒀습니다 — 7곳 모두 내용이 동일합니다) | — | 팀 공용 (원 작성자 미상) |

## 실행 순서

`src/2_승률모델/01_train_model.py`로 기본 모델을 먼저 학습해야 합니다. 그 뒤 `01` `02` `03`은 서로 독립적이라 순서 없이 실행 가능하며, 마지막에 `04_reports_v123.py`를 실행하면 세 결과를 정리한 HTML이 나옵니다.

> 표의 `results/...` 는 실행하면 로컬에 생기는 결과 폴더입니다. 저장소에는 올리지 않습니다.
