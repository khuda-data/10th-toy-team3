# 개발 16단계 결과 — 경주 단위 Paired Bootstrap

생성 시점: 2026-08-18 02:23 KST

## 방법

- 입력: 동결된 Final Test 예측 635경주
- 표본 단위: `race_id`
- 방식: 시장과 모델에 같은 경주 표본을 적용하는 paired bootstrap
- 복원추출 횟수: 5,000회
- 난수 시드: 42
- 신뢰구간: 95% percentile interval
- Delta 방향: `시장 손실 - 모델 손실`; 양수이면 모델 우위
- 모델과 정책 변경: 없음

## M2 고정 후보 결과

| 지표 | Point Delta | 95% CI | 모델 우위 확률 | CI 하한 > 0 |
|---|---:|---:|---:|---|
| Race Log Loss | +0.003902 | **[+0.001085, +0.006721]** | 99.48% | 예 |
| Race Brier | +0.000602 | [-0.000483, +0.001687] | 84.88% | 아니오 |
| Top-1 | -0.003150 | [-0.009449, +0.003150] | 9.68% | 아니오 |

M2의 Race Log Loss 개선은 bootstrap 95% 신뢰구간 전체가 0보다 커서 통계적으로 지지된다. Brier는 point estimate가 개선 방향이고 bootstrap 표본의 84.88%에서 모델이 우수했지만 신뢰구간이 0을 포함한다.

## M1 참고 결과

| 지표 | Point Delta | 95% CI | 모델 우위 확률 |
|---|---:|---:|---:|
| Race Log Loss | +0.002409 | [-0.000463, +0.005223] | 94.72% |
| Race Brier | +0.000013 | [-0.001070, +0.001077] | 50.24% |

M1은 두 주요 지표 모두 신뢰구간이 0을 포함한다.

## 결론

프로젝트의 엄격한 성공 조건은 두 주요 지표의 95% 신뢰구간 하한이 모두 0보다 큰 것이다. M2는 Log Loss 조건만 통과하고 Brier 조건은 통과하지 못했으므로 다음과 같이 결론낸다.

```text
M2는 시장보다 더 나은 확률을 산출할 가능성이 있으며,
Race Log Loss 개선은 통계적으로 지지된다.
그러나 Brier 개선은 아직 불확실하므로
시장에 대한 안정적 종합 우위는 확정되지 않았다.
```

이 결과는 Final Test를 이용한 기술적 추론이며 추가 튜닝이나 모델 선택에 사용하지 않는다. 다음 개발 단계는 17단계 경제적 백테스트다.
