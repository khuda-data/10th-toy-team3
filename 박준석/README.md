# 박준석 — 로컬 신규 작업 (2026-08-22)

레포가 `src/N_단계`·`reports/N_단계` 구조로 정리된 뒤, 제 로컬에서 새로 진행된 작업만 모은 폴더입니다. **기존에 정리된 다른 폴더는 건드리지 않고, 이 폴더에만 새로 추가했습니다.**

이 폴더의 내용은 README의 「프로젝트 흐름」 표 7단계 — **이변 탐지 모델 선정** (`reports/5_이변모델_선정/모델선정.docx`, RandomForest·Lift@10% 1.72배)의 소스 코드입니다. 그 보고서는 이미 레포에 있는데 코드가 "정리 예정"으로 비어 있던 부분이라, 여기 채워 넣었습니다.

## 폴더 지도

| 폴더/파일 | 내용 |
|---|---|
| `이변모델_선정_코드/` | 6단계 개선 실험 → 최종 전략(배당 필터) → 이변마 인사이트(군집·의사결정나무) → 배팅 배분 전략 → 종합 보고서까지의 코드 5개(`11`~`15`) + 공용 `config.py`. 파일별 설명은 폴더 내 README 참고 |
| `이변모델_선정_결과/` | 위 코드를 실행해서 나온 표·그래프 9개. 파일별 설명은 폴더 내 README 참고 |
| `이변_예측모델_최종전략_보고서.docx` | `13_final_report_docx.py`의 산출물 — 배당 구간 필터 최종 전략 상세 보고서 |

## 참고

- `config.py`는 팀 공용 파이프라인 설정 모듈이라 실행에 필요해서 코드 폴더에 복사해뒀습니다.
- 코드는 레포의 `src/4_이변모델/08_full_pipeline.py`가 만든 C모델 결과를 입력으로 사용합니다.
