# 최종 발표 자료

이 폴더가 발표 내용의 최상위 기준입니다.

사용자가 확정한 스토리라인 원문은 수정하지 않고 보존했습니다. 아래 감사 메모는 원문을 몰래 바꾸기 위한 것이 아니라, 발표 수치와 근거를 확정하기 전에 확인해야 할 사항을 분리해 기록한 것입니다.

| 파일 | 내용 |
|---|---|
| [`최종_스토리라인.md`](최종_스토리라인.md) | 확정된 파트 1·파트 2 발표 흐름 |
| [`자료_인덱스.md`](자료_인덱스.md) | 발표 주장과 저장소 근거자료의 연결 |
| [`최신_백테스트_요약.csv`](최신_백테스트_요약.csv) | 2026-08-10~2026-08-23 서울 51경주 전략 비교 |
| [`서울경마_예측전략_비교_백테스트.docx`](서울경마_예측전략_비교_백테스트.docx) | 최신 백테스트 원본 보고서 |

최신 백테스트는 51경주·25건의 이변 베팅이라는 짧은 기간 결과입니다. 이변예측의 ROI +4.8%는 양의 점추정치지만 신뢰구간이 0을 포함하므로 통계적으로 유의한 수익으로 표현하지 않습니다.

## 재현성 주의

현재 `main`에는 최신 서울 51경주의 경주별 원시 예측·정산 행과 이를 생성한 실행 코드가 확인되지 않았습니다. 따라서 이 폴더는 사용자가 제공한 결과 문서와 요약 수치를 보존하지만, 해당 최신 예측을 저장소만으로 완전히 재실행하는 근거 묶음은 아닙니다. 완전한 재현을 위해서는 이후 원시 입력 스냅샷, 경주별 선택 결과, 정산 행, 실행 환경을 함께 추가해야 합니다.

## 파트 1 근거 감사

- 발표문의 `102개`와 엄격한 비시장 피처 `100개` 사이에 정의 차이가 있습니다. 상세 열 목록은 [`../../1_변별력/피처수_감사.md`](../../1_변별력/피처수_감사.md)에 기록했습니다.
- 기존 v5 4모델 결과는 당일 발매금액 파생변수를 포함하므로 최종 비시장 근거에서 제외했습니다. 네 모델의 정확한 Test 표는 [`../../1_변별력/3차_4모델비교_재실행필요/README.md`](../../1_변별력/3차_4모델비교_재실행필요/README.md)의 계약으로 재실행해야 합니다.
- 확률 품질 수치는 시장 앵커·혼합 결과가 아니라 [`../../2_확률품질/발표근거/독립모델_test_지표.csv`](../../2_확률품질/발표근거/독립모델_test_지표.csv)의 독립 Logistic·XGBoost 결과를 사용합니다.
