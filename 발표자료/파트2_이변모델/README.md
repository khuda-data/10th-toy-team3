## 배당률의 역설 — 이 보고서의 축

피처로 넣으면 성능이 크게 오릅니다.

| 피처셋 | 구성 | 다크호스 AUC |
|---|---|---:|
| A 배당률만 | `q` **1개** | **0.737** |
| B 피처만 | ~**110개** (배당 완전 제외) | **0.657** |
| C 결합 | `q` + 110개 | **0.742** |

**배당률 하나가 피처 110개보다 낫습니다.** 파트 1의 정보 비대칭이 그대로 재현됩니다.

**그런데 쓸 수 없습니다.** 한국마사회 API 필드명이 `winOdds` = "단승식**확정**배당"입니다.
베팅 마감 **후** 확정되는 값이라, 피처로 쓰면 미래를 보고 과거를 판단하는 셈입니다.
마감 전 실시간 배당을 주는 공식 API는 없습니다.

그리고 쓸 수 있었다 해도 더 나은 선택이 아니었습니다.

| | AUC | test ROI | 홀드아웃 유의 | 부경 재학습 |
|---|---:|---:|:---:|---:|
| C모델 (`q` 포함) | **0.742** | **+32.0%** | **아니오** | **−44.6%** |
| 다크호스 (`q` 제외) | 0.645 | +11.5% | **예** | −19.8% |

**"정확도"와 "실전 수익"은 다른 차원입니다.**

## ⚠ 인용할 때 주의

**① 부록 D의 "유의" 표시를 그대로 쓰지 마세요.** 28개 조합 중 20개에 붙어 있지만
전부 test 기준이고 베팅 건수가 21~56건짜리입니다. 실제로 `plcOdds ≥ 10배` 필터(test ROI +268.6%)를
홀드아웃에 적용하니 16건 중 3적중, CI `[-100%, +7758%]`로 무너졌습니다.

**② 배분 전략의 Kelly/EV 수치를 쓰지 마세요.** ROI +116.2%가 나오지만
기저 ROI 자체가 소수 고배당 의존이라 불안정성만 증폭시킵니다. 실무 권장은 **균등 배분**입니다.

**③ 조합 전략(+36.4%)은 test만 확인됐습니다.** 홀드아웃 미검증이라 "유망한 후보"까지입니다.

**④ 다크호스 정의는 "입상(3착 이내)"입니다.** 이전 문서에 "1착"으로 잘못 적혀 있었고,
박준석님이 데이터 교차검증으로 정정했습니다(입상 100% · 1착 19.8%).
**이제 박준석·김찬진 두 분의 정의가 같아 Lift를 나란히 비교할 수 있습니다.**
